# EXP020: CTE vs Inline Derived Table

**Category:** CTEs  
**Difficulty:** Beginner  
**Tags:** CTE, QueryDesign, Inlining

## Description
Expresses the same date-filtered aggregate as a CTE and an inline derived table.

## Problem Statement
CTEs are often mistaken for materialized intermediate results.

## Expected Outcome
The scalar totals match and SQL Server will commonly produce equivalent plans.

## Performance Theory
A nonrecursive CTE is generally an expression expanded into the surrounding query, not a storage boundary.

## Diagnostic Expectations
Expect similar metrics; treat any difference as observed behavior rather than assuming syntax alone guarantees it.

## Plan Expectations
Compare plan hashes and operators. The optimizer may normalize both forms to the same plan.
