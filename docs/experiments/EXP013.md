# EXP013: Hash Aggregate

**Category:** Aggregations  
**Difficulty:** Intermediate  
**Tags:** HashAggregate, Memory, GroupBy

## Description
Groups customers into 100 buckets and compares hash and ordered aggregation.

## Problem Statement
Higher group cardinality can increase aggregate memory requirements and trigger spills.

## Expected Outcome
The grouped scalar totals match; the plan and grant can differ by strategy.

## Performance Theory
Hash grouping stores group state in a hash table; ordered grouping depends on input order and may need a sort.

## Diagnostic Expectations
Inspect requested/granted/used memory, TempDB pages, reads, and CPU.

## Plan Expectations
Look for Hash Match (Aggregate), Stream Aggregate, and Sort operators. Spill behavior varies by server memory.
