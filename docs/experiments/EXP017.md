# EXP017: Memory Grant and Aggregation

**Category:** Resource Usage  
**Difficulty:** Intermediate  
**Tags:** MemoryGrant, HashAggregate, ResourceUsage

## Description
Compares aggregate strategies over the full Orders table while collecting runtime grant information.

## Problem Statement
Memory grants reserve workspace for operators such as hash aggregates and sorts.

## Expected Outcome
The scalar total is equal. A grant may be absent or zero for this query and server configuration.

## Performance Theory
Over-grants reduce concurrency; under-grants can cause spills. Grant requirements follow estimated row counts and operator needs.

## Diagnostic Expectations
Review requested, granted, and used KB, TempDB pages, and `sampleCount`; do not interpret unavailable values as zero.

## Plan Expectations
Inspect aggregate operators and grant information in the runtime plan XML.
