# EXP003: Clustered Index vs Heap

**Category:** Indexing  
**Difficulty:** Intermediate  
**Tags:** Clustered, Heap, Storage

## Description
Copies the seeded rows to a heap and compares an OrderId range aggregate with the clustered primary-key table.

## Problem Statement
A heap has no key order for range access, while the clustered index stores rows by its key.

## Expected Outcome
The clustered table should efficiently locate the OrderId range; setup and teardown of the heap occur outside measured iterations.

## Performance Theory
Clustered key order can support range navigation and co-locate requested rows. A heap requires allocation-order access unless another index exists.

## Diagnostic Expectations
Compare logical reads, CPU, and elapsed time. The full heap copy is setup work and is not part of the benchmark query timing.

## Plan Expectations
Expect a scan on the heap and a clustered index range access on `dbo.Orders`.
