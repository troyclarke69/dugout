# EXP007: Nested Loops Join

**Category:** Joins  
**Difficulty:** Intermediate  
**Tags:** NestedLoops, Join, Selectivity

## Description
Runs an equivalent selective self-join with a forced Nested Loops baseline and Hash Join comparison.

## Problem Statement
Join strategy suitability depends on input size and available access paths.

## Expected Outcome
Nested Loops can work well for small outer inputs; a hash join may have different CPU and memory costs.

## Performance Theory
Nested Loops probes the inner input per outer row. Hash joins build and probe a hash structure.

## Diagnostic Expectations
Compare CPU, elapsed time, memory-grant values, and logical reads; no strategy is universally faster.

## Plan Expectations
The baseline requests Nested Loops and the comparison requests Hash Match. Confirm actual operators in the plan.
