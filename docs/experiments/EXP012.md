# EXP012: Stream Aggregate

**Category:** Aggregations  
**Difficulty:** Intermediate  
**Tags:** StreamAggregate, Ordering, GroupBy

## Description
Groups orders by date and compares hash aggregation with ordered aggregation.

## Problem Statement
An ordered aggregate can avoid a hash structure only when its input order is available or produced efficiently.

## Expected Outcome
Results are identical. The preferred plan depends on the cost of sorting versus hashing.

## Performance Theory
Stream aggregation has low per-group state but requires ordered input; hash aggregation requires a hash table.

## Diagnostic Expectations
Compare grant and TempDB metrics alongside CPU and elapsed time.

## Plan Expectations
Check for Stream Aggregate, Hash Match (Aggregate), and any Sort operator.
