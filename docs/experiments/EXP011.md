# EXP011: GROUP BY Optimization

**Category:** Aggregations  
**Difficulty:** Beginner  
**Tags:** GroupBy, HashAggregate, StreamAggregate

## Description
Compares hash grouping with ordered grouping, then reduces grouped values to a scalar result.

## Problem Statement
Aggregation strategy affects memory and sorting requirements.

## Expected Outcome
Both forms return the same total. Their resource use depends on whether useful input order exists.

## Performance Theory
Hash aggregates build groups in memory; stream aggregates consume rows ordered by group keys.

## Diagnostic Expectations
Inspect memory grants, TempDB usage, CPU, and logical reads.

## Plan Expectations
The baseline requests Hash Aggregate; the comparison requests ordered aggregation.
