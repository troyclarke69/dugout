# EXP019: Parallel Query

**Category:** Resource Usage  
**Difficulty:** Intermediate  
**Tags:** Parallelism, MAXDOP, CPU

## Description
Compares the same table aggregate with MAXDOP 1 and MAXDOP 2.

## Problem Statement
Parallel execution can reduce elapsed time while increasing coordination and CPU costs.

## Expected Outcome
Both totals match. A parallel plan is not guaranteed; server settings and cost thresholds control eligibility.

## Performance Theory
Parallel plans divide work across workers and introduce exchange operators.

## Diagnostic Expectations
Compare DOP, parallel operator count, CPU, elapsed time, and logical reads.

## Plan Expectations
Look for Parallelism exchange operators. The local Docker SQL Server has a constrained CPU allocation, so results are environment-specific.
