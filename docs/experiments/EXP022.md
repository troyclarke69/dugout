# EXP022: Data Type Conversion on Predicates

**Category:** Data Types  
**Difficulty:** Beginner  
**Tags:** ImplicitConversion, SARGability, DataTypes

## Description
Creates an index on CustomerId, then compares converting the column to text with a correctly typed integer predicate.

## Problem Statement
Applying a conversion to a column can make an otherwise searchable predicate non-SARGable.

## Expected Outcome
Both predicates select CustomerId 25; direct integer comparison should be easier to optimize.

## Performance Theory
Type precedence and conversion placement affect whether SQL Server converts a parameter or every row's column value.

## Diagnostic Expectations
Compare reads and CPU. The setup index is isolated to this experiment and removed in cleanup.

## Plan Expectations
Inspect scalar conversions and access predicates in the plan XML.
