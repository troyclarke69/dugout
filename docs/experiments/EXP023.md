# EXP023: Sort Strategy and Top N

**Category:** Sorting  
**Difficulty:** Intermediate  
**Tags:** Sort, TopN, MemoryGrant

## Description
Sums row numbers ordered by date and compares the order-independent rank sum with a count formula.

## Problem Statement
Sorting large inputs can require memory grants and TempDB workspace.

## Expected Outcome
Both variants return N(N+1)/2 for the same number of rows.

## Performance Theory
Top-N sorts can use bounded memory when only a prefix is needed; this example ranks all rows to expose full ordering work.

## Diagnostic Expectations
Inspect requested/granted/used memory, TempDB pages, Worktable reads, and spill warnings.

## Plan Expectations
The baseline may require Sort and Window Aggregate operators. Runtime memory and spill behavior varies by SQL Server version and available memory.
