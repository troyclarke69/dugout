# EXP015: Parameter Sensitivity

**Category:** Parameter Sniffing  
**Difficulty:** Advanced  
**Tags:** ParameterSensitivity, OptimizeFor, Cardinality

## Description
Compares a parameterized predicate optimized for an unknown value with a literal predicate.

## Problem Statement
A generic plan can trade value-specific efficiency for more stable behavior across parameter values.

## Expected Outcome
Both variants return the selected customer's total; estimates and plan operators can differ.

## Performance Theory
Parameter values influence cardinality estimates during compilation. The base Orders customer distribution is mostly uniform, so this experiment isolates mechanics rather than extreme skew.

## Diagnostic Expectations
Inspect estimated/actual rows, reads, CPU, elapsed time, and plan hashes.

## Plan Expectations
Compare access operators and estimates. EXP014 supplies the deliberately skewed data example.
