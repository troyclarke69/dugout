# EXP018: TempDB Sort and Spill Signals

**Category:** TempDB  
**Difficulty:** Advanced  
**Tags:** TempDB, Sort, Spill

## Description
Computes the sum of row numbers ordered by TotalAmount and compares the count-based identity for that rank sum.

## Problem Statement
Large sorts can consume memory and spill work to TempDB.

## Expected Outcome
The sum of row numbers is N(N+1)/2 for any ordering of N rows, so both variants return the same scalar.

## Performance Theory
The baseline requires an ordered window operation; the comparison uses a closed-form aggregate. The optimizer may transform either query.

## Diagnostic Expectations
Inspect TempDB page deltas, Worktable/Workfile reads, grant usage, and sort spill warnings. A spill is environment-dependent.

## Plan Expectations
The baseline may show Sort and Window Aggregate operators. Check runtime warnings rather than assuming a spill occurred.
