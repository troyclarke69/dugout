# EXP021: Window Function vs Arithmetic Aggregate

**Category:** Window Functions  
**Difficulty:** Advanced  
**Tags:** WindowFunction, RunningTotal, Sort

## Description
Sums a running-total window and compares the equivalent weighted sum over seeded OrderId values.

## Problem Statement
Running totals require ordered processing and may introduce a sort or window operator.

## Expected Outcome
The formulas match for the seeded contiguous OrderId range 1 through 1,000,000.

## Performance Theory
Each row's OrderId contributes to its own and all later running totals, giving weight N-OrderId+1.

## Diagnostic Expectations
Compare sort/worktable signals, CPU, elapsed time, and TempDB pages.

## Plan Expectations
The baseline should expose windowing and ordering work. The arithmetic form depends on the documented identity-sequence assumption.
