# EXP005: Filtered Index

**Category:** Indexing  
**Difficulty:** Intermediate  
**Tags:** FilteredIndex, Date, SARGability

## Description
Creates an index filtered to 2025 rows and compares `YEAR(OrderDate)` with a half-open date range.

## Problem Statement
A filtered index is useful only when the query predicate can prove it applies to the indexed subset.

## Expected Outcome
The SARGable range can use the filtered index; the scalar year expression may scan or fail to match its filter.

## Performance Theory
Filtered indexes reduce index size and improve selectivity for queries confined to the filter predicate.

## Diagnostic Expectations
Compare logical reads and CPU. The filtered index is created before benchmarking and dropped during cleanup.

## Plan Expectations
The optimized plan should be eligible for the filtered index. Always inspect the actual captured operator and predicate.
