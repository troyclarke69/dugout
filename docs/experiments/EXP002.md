# EXP002: Missing Covering Index

**Category:** Indexing  
**Difficulty:** Intermediate  
**Tags:** Index, Covering, Lookup

## Description
Creates a narrow CustomerId index and a covering counterpart, then runs the same aggregate through each index.

## Problem Statement
A seek can still require repeated base-row lookups when projected columns are absent from the index.

## Expected Outcome
The covering index should satisfy the query without a Key Lookup and generally reduce reads.

## Performance Theory
Included columns extend leaf-level coverage without changing the index key order.

## Diagnostic Expectations
Compare logical reads and CPU. This experiment's setup creates isolated P6 indexes and cleanup removes them.

## Plan Expectations
The narrow index may produce a Key Lookup; the covering index should remove it. Confirm this in the captured operator list.
