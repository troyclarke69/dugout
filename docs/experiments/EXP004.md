# EXP004: Key Lookup Elimination

**Category:** Indexing  
**Difficulty:** Intermediate  
**Tags:** KeyLookup, CoveringIndex, Reads

## Description
Uses narrow and covering CustomerId indexes for the same TotalAmount aggregate.

## Problem Statement
A noncovering seek retrieves qualifying keys, then performs lookups for the aggregate's value column.

## Expected Outcome
Including TotalAmount should eliminate the lookup operator and reduce page access.

## Performance Theory
Lookup cost grows with qualifying row count; covering access reads the required value from the index itself.

## Diagnostic Expectations
Look for reduced logical reads and CPU. Setup and cleanup manage only indexes prefixed `IX_P6_`.

## Plan Expectations
Baseline may contain Key Lookup plus an index seek; optimized should use the covering index without that lookup.
