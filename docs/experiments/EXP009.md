# EXP009: Hash Match Join

**Category:** Joins  
**Difficulty:** Intermediate  
**Tags:** HashMatch, NestedLoops, Join

## Description
Compares Hash Match and Nested Loops on a larger filtered self-join.

## Problem Statement
A join strategy that works for tiny inputs may become expensive as cardinality grows.

## Expected Outcome
The plans remain result-equivalent; relative resource use depends on optimizer estimates and runtime conditions.

## Performance Theory
Hash joins trade memory and build work for fewer repeated probes; Nested Loops repeatedly accesses the inner input.

## Diagnostic Expectations
Compare CPU, elapsed time, logical reads, memory grants, and TempDB signals.

## Plan Expectations
The baseline requests Hash Match; the comparison requests Nested Loops.
