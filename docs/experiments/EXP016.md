# EXP016: Plan Reuse and Recompile

**Category:** Parameter Sniffing  
**Difficulty:** Advanced  
**Tags:** PlanReuse, Recompile, Parameters

## Description
Compares a local-variable plan with statement-level recompilation for the same value.

## Problem Statement
Recompilation may improve value-specific estimates but incurs compile work.

## Expected Outcome
Results match; compilation metadata and resource measurements may vary.

## Performance Theory
Plan reuse amortizes compilation across executions, while `OPTION (RECOMPILE)` creates a value-specific plan per execution.

## Diagnostic Expectations
Compare duration and SQL CPU with care: this is a short query where compilation overhead can be visible.

## Plan Expectations
Inspect plan hashes and estimated rows. The runner captures an estimated plan before measuring executions.
